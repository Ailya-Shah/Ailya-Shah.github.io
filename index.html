Bitcoin Trend Prediction

An end-to-end pipeline that forecasts short-term Bitcoin direction: automated ingestion (Binance, on-chain, FRED), a nine-notebook analysis pipeline, classical ML benchmarked head-to-head against a neural net, and a cost-aware backtest — leakage-aware throughout.

50.7% best-model directional accuracy. Next-day direction is close to a coin flip — so the dashboard says exactly that, instead of a number that flatters.
